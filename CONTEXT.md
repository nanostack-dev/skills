# Skill library vocabulary

| Term | Meaning |
| --- | --- |
| Skill | A directory whose SKILL.md supplies a trigger and an executable agent procedure. |
| Invocation policy | Whether a user must explicitly request a procedure or an agent may select it implicitly. |
| Completion criterion | Evidence required before the skill can report its work complete. |
| Supporting resource | A script, template, reference or viewer disclosed by the skill as needed. |
| Plugin | Packaged discovery of this library through its tracked Claude marketplace metadata. |
| Raw consumer | Agent loading a SKILL.md and its relative supporting resources through GitHub URLs. |
| Pinned consumer | Installer loading a particular commit rather than following main. |
| Project adapter | Local project guidance supplying concrete commands/data to a generic skill. |

[README.md](README.md) lists the current skill catalog; [architecture](docs/technical/architecture.md) owns packaging.
